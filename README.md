# School Management System

A console-based School Management System built using C++ that enables teachers and students to manage academic records efficiently.

## Features
- Add, search, and modify student records
- Generate report cards and ID cards
- Calculate percentage and grades automatically
- View class statistics
- Simulated fee payment system (Card/UPI)
- Input validation and exception handling

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling

## Run
```bash
g++ SDFII_PBL.cpp -o school_management
./school_management
